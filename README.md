# bionic-reader
Convert the visible text on any webpage into Bionic Reading for faster reading speed and comprehension, in one bookmark click!

Designed for Chrome and Firefox.

What is Bionic Reading?
Developed by Renato Casuut, Bionic Reading is a technique to increase reading speed and comprehension by bolding a part of each word to read.

How to use:
1. Create a new bookmark, replace the URL with the text in bionic-reader.js, and save the bookmark.
2. Click the bookmark from a webpage in which you want to read the text with Bionic Reading.
